# Oxi Elite Design

Create a completely new, ultra-premium and professional roofing website for **Oxi Roofing 504**.

Business details:

* **Business Name:** Oxi Roofing 504
* **Email:** [oficialoxitmc@gmail.com](mailto:oficialoxitmc@gmail.com)
* **Location:** Metairie Lakefront, Louisiana, USA
* **Instagram:** @el_oxi_504
* **TikTok:** @oxicapivara

The website must NOT look like a generic roofing template. Make it feel ultra-premium, cinematic, modern, editorial and visually impressive from the moment the website opens.

## Design & Color Style

Use a sophisticated combination of:

* Warm White
* Warm Chocolate
* Warm Black

Create strong contrast so all text is easy to read. Use warm white for clean space, chocolate tones for elegant premium accents, and warm black for cinematic depth.

Use smooth scrolling, subtle Framer Motion animations, premium hover effects and scroll-based reveals. The website should feel expensive and polished without becoming too dark or difficult to read.

## Hero Section

Create an extremely unique and luxurious hero section.

Do not use a normal centered heading with a simple background image.

Use a cinematic roofing visual composition with large typography, layered elements, subtle motion, premium image treatment and depth.

Main focus: **Oxi Roofing 504**

Add a strong roofing-related headline and CTA buttons such as:

**Get a Quote**
**View Our Work**

The hero should immediately make the business look established, professional and high-end.

## About Section

Create a premium editorial About section introducing Oxi Roofing 504.

Use a modern asymmetric layout with a high-quality temporary roofing/team image and elegant typography.

Keep the content professional, trustworthy and focused on quality workmanship and roofing expertise.

## Services / What We Do

Create an impressive services section instead of a basic card grid.

Use an editorial mixed layout with premium roofing images, subtle animations and visual hierarchy.

Include realistic services such as:

* Roof Repairs
* Roof Replacement
* Storm Damage Repair
* Roof Inspections
* Roofing Maintenance

Make the section visually dynamic and premium.

## Recent Projects

Create a **Recent Projects** section.

Supporting text:

**Real roofs. Real work. Built to last.**

Create 4 realistic roofing project cards using premium temporary roofing images.

Use an animated stacked-card and scroll-reveal style.

The cards should progressively reveal while scrolling with depth, scale, translate and opacity animations.

Each project should contain:

* Project title
* Project type
* Short description
* Roofing image

Make this section cinematic and visually impressive.

## Before & After

Create a premium interactive **Before & After** section.

Use a large image comparison slider with realistic temporary roofing images.

The slider should be smooth, easy to use and visually satisfying.

Make this section a major visual highlight of the website.

## Reels

Create a premium **Reels** section.

Supporting text:

**See the real work, straight from the roof.**

Use 4 temporary roofing-related vertical videos.

Videos must be:

* 9:16
* Autoplay
* Muted
* playsInline
* Loop

Use a premium interactive gallery where users can drag or scroll through the reels.

One main video should be prominent while nearby videos are partially visible.

The interaction should feel cinematic, tactile and modern rather than like a simple video grid.

## Testimonials

Create a premium **Testimonials** section.

Supporting text:

**Trusted work. Real experiences.**

Use an animated layered card-stack design.

Do NOT use a basic four-column review grid.

Testimonials should reveal and transform during scrolling with subtle depth and perspective.

Make the section feel editorial and high-end.

## Contact Section

Create a premium final contact section that feels like a strong closing experience.

Include:

* Oxi Roofing 504
* [oficialoxitmc@gmail.com](mailto:oficialoxitmc@gmail.com)
* Metairie Lakefront, Louisiana

Add clear CTA buttons for contacting the business.

Use an elegant layout with warm chocolate and warm black visual elements.

## Footer

Create a clean and premium footer with:

* Business Name
* Email
* Instagram
* TikTok
* Location
* Navigation links

Keep it elegant and minimal.

## Navbar

Create a premium responsive navigation with:

* About
* Services
* Projects
* Before / After
* Reels
* Testimonials
* Contact

Add smooth scrolling to every section.

## Animation & Quality Rules

Use premium but smooth animations throughout the website:

* Scroll reveal
* Subtle parallax
* Image zoom
* Layered movement
* Fade and translate transitions
* Premium hover effects

Do not overuse animations.

Everything must feel smooth, expensive and professional.

## Mobile Responsiveness

The entire website must be fully responsive.

On mobile:

* No horizontal overflow
* No unwanted scrollbar
* Videos remain 9:16
* Cards resize correctly
* Text remains readable
* Touch and drag interactions work naturally
* Normal vertical scrolling remains smooth

## Final Goal

The final website should feel like a premium modern roofing brand, not a cheap or generic contractor website.

Think:

**Cinematic · Editorial · Luxurious · Modern · Strong · Premium · Craftsmanship-focused**

Make every major section visually different so the website never feels repetitive or boring.

The Hero, Services, Projects, Before & After, Reels and Testimonials should each have their own unique visual experience while maintaining one consistent warm white, warm chocolate and warm black brand identity.
